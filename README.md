# MergeWorks  
A3横サイズ｜画像2枚を自動合成するブラウザツール

**ブラウザ上で動作する、A3横サイズ専用の画像マージツールです。**  
画像を2枚選んで「合成する」ボタンを押すだけで、POP制作に使えるA3横画像を即座に生成します。

👉 **今すぐ使う（GitHub Pages）**  
https://sk569ppups.github.io/MergeWorks/

---

## 🚀 主な特徴

- 画像2枚を選択するだけで自動セット
- A3横サイズに自動リサイズ＆合成
- 生成画像はそのままローカルに保存可能
- サーバーに画像を送信しない安全設計
- インストール不要／完全ブラウザ動作

---

## 🖼️ 使い方

1. 上記URLにアクセス  
2. 画像①・画像②を選択  
3. 「合成する」ボタンをクリック  
4. 生成された画像を保存

※ PCブラウザ推奨

---
